# Справочники корпусных метаданных

Каталог содержит справочники подкорпусов, жанров и диалектов ВепКар. Они позволяют интерпретировать значения полей `corpus_id`, `genre_id` и `dialect_code` в [`texts_<lang>.csv.zst`](../README.ru.md).

Справочники выгружаются целиком, без ограничения записями, использованными в текстах четырёх проектных языков.

```text
texts_<lang>.csv
    |
    +-- corpus_id ------> corpora.csv
    |
    +-- genre_id -------> genres.csv
    |                         |
    |                         +-- parent_id --> genres.csv
    |                         +-- corpus_id --> corpora.csv
    |
    +-- dialect_code ---> dialects.csv
```

## Формат

Файлы небольшие и хранятся без сжатия:

- кодировка — UTF-8;
- разделитель — запятая;
- первая строка — заголовок;
- кавычки внутри заключённых в кавычки полей удваиваются;
- SQL `NULL` записывается как `\N`;
- пустая ячейка означает пустую строку;
- строки отсортированы по первичному идентификатору.

Значения сохраняются из исходной БД без исправлений и подстановок. Например, отсутствие английского названия не компенсируется русским названием.

Буквальное исходное значение `\N` конфликтует с маркером `NULL`; экспортёр проверяет такие коллизии и останавливает выгрузку при их обнаружении.

## `corpora.csv`

Одна строка — один корпус или подкорпус ВепКар.

Источник: таблица `corpuses`.

```csv
corpus_id,name_en,name_ru
```

| Поле | Описание |
|---|---|
| `corpus_id` | Первичный идентификатор, `corpuses.id` |
| `name_en` | Название на английском |
| `name_ru` | Название на русском |

`corpus_id` связывает справочник с одноимённым полем в `texts_*` и с полем `corpus_id` в `genres.csv`.

## `genres.csv`

Одна строка — один жанр. Справочник сохраняет иерархию жанров и связь жанра с подкорпусом.

Источник: таблица `genres`.

```csv
genre_id,parent_id,corpus_id,sequence_number,name_en,name_ru,name_pl_en,name_pl_ru
```

| Поле | Описание |
|---|---|
| `genre_id` | Первичный идентификатор, `genres.id` |
| `parent_id` | Идентификатор родительского жанра; `0` используется для корневых жанров. SQL `NULL`, если присутствует в источнике, сохраняется как `\N` |
| `corpus_id` | Идентификатор корпуса или подкорпуса из `corpora.csv` |
| `sequence_number` | Порядок показа в ВепКар; не идентификатор жанра |
| `name_en`, `name_ru` | Названия в единственном числе |
| `name_pl_en`, `name_pl_ru` | Названия во множественном числе |

`parent_id = 0` — обозначение корня, а не ссылка на обязательную запись с `genre_id = 0`.

Пустые и отсутствующие названия сохраняются буквально. Экспортёр не вычисляет множественное число и не подставляет вместо него единственное.

Иерархия позволяет строить укрупнённые исследовательские группы. Такие группировки являются производными данными и не записываются обратно в справочник.

## `dialects.csv`

Одна строка — один диалект или говор, зарегистрированный в ВепКар.

Источники: таблица `dialects` и код языка из `langs`.

```csv
dialect_id,dialect_code,lang_code,sequence_number,name_en,name_ru
```

| Поле | Описание |
|---|---|
| `dialect_id` | Первичный идентификатор, `dialects.id` |
| `dialect_code` | Код диалекта, `dialects.code`; используется в `texts_*.dialect_code` |
| `lang_code` | Код языка из `langs.code` |
| `sequence_number` | Порядок показа в ВепКар |
| `name_en`, `name_ru` | Названия на английском и русском |

`dialect_id` также позволяет интерпретировать диалектные ссылки в [`dict/morphology/lemma_wordforms_*`](../../dict/morphology/README.ru.md).

Код языка присоединяется левым соединением: отсутствие связанной записи языка не удаляет диалект из выгрузки. Такое отсутствие отражается значением `\N` и требует проверки качества данных.

## Соединение с метаданными текстов

В `texts_*` поля `corpus_id`, `genre_id` и `dialect_code` могут содержать несколько значений, разделённых `|`.

Например:

```text
corpus_id = 1|3
```

означает две ссылки на `corpora.csv`, а не один составной идентификатор.

Перед соединением со справочником:

1. Прочитайте файл стандартным CSV-парсером.
2. Разделите непустое значение соответствующего поля по `|`.
3. Соедините отдельные элементы со справочником.

Не интерпретируйте порядок элементов как приоритет. При подсчётах учитывайте множественную принадлежность: один текст может попасть в несколько групп.

Не теряйте исходные записи из-за неразрешённых ссылок: используйте левое соединение и отдельно проверяйте отсутствующие соответствия.

## Чтение через pandas

```python
import pandas as pd

genres = pd.read_csv(
    "corpus/reference/genres.csv",
    dtype=str,
    keep_default_na=False,
    na_values=[r"\N"],
)
```

При таком чтении `\N` становится пропущенным значением, а пустая ячейка сохраняется как пустая строка.

Правило `\N` относится к этим справочникам. Оно не должно автоматически применяться ко всем остальным корпусным CSV: их правила описаны в [README корпуса](../README.ru.md).
