# Словарная морфология

Каталог содержит все леммы ВепКар и связи лемм со словоформами для четырёх языковых разновидностей. Выгрузка не ограничена словами, встречающимися в корпусе.

```text
lemmas_<lang>.csv.zst
        │
        │ lemma_id
        ▼
lemma_wordforms_<lang>.csv.zst
        │
        │ gramset_id
        ▼
../grammar/gramsets.csv
```

`<lang>` означает один из кодов: `vep`, `krl`, `olo`, `lud`. Язык файла определяется языком леммы.

В [`samples/`](samples/) находятся небольшие несжатые примеры для собственно карельского наречия. Строки отобраны вручную, чтобы показать разные значения полей: это не случайная выборка и не материал для исследовательской оценки.

## Пустые значения

В этих файлах SQL `NULL` и пустая строка различаются:

| Значение ячейки | Смысл |
|---|---|
| `\N` | SQL `NULL` |
| пустая ячейка | пустая строка |
| любое другое | исходное значение |

Чтобы сохранить это различие в pandas, отключите стандартные пропуски:

```python
import pandas as pd

wordforms = pd.read_csv(
    "lemma_wordforms_krl.csv.zst",
    compression="zstd",
    dtype=str,
    keep_default_na=False,
    na_values=[r"\N"],
)
```

## `lemmas_<lang>.csv.zst`

Схема:

```csv
lemma_id,lemma,lang,pos_id,pos
```

| Поле | Значение |
|---|---|
| `lemma_id` | Идентификатор леммы. Уникален; на него ссылаются `lemma_wordforms_<lang>` и `../meanings_<lang>.csv.zst`. |
| `lemma` | Написание леммы. |
| `lang` | Код языка. |
| `pos_id` | Идентификатор части речи; присоединяется к `../grammar/parts_of_speech.csv`. Может быть `\N`. |
| `pos` | Код части речи. Может быть `\N`. |

Сюда входят и леммы, у которых нет словоформ или словарных значений.

## `lemma_wordforms_<lang>.csv.zst`

Схема:

```csv
wordform_id,wordform,wordform_for_search,lemma_id,gramset_id,dialect_id,dialect_code,affix
```

| Поле | Значение |
|---|---|
| `wordform_id` | Идентификатор словоформы; совпадает с `wordform_id` в `../../corpus/candidate_analyses_<lang>.csv.zst`. |
| `wordform` | Словоформа в словарном написании. |
| `wordform_for_search` | Сохранённая форма для поиска. Может отличаться от `wordform`, например `aštuis’` → `aštuis`. |
| `lemma_id` | Идентификатор леммы. |
| `gramset_id` | Идентификатор грамматического набора; присоединяется к `../grammar/gramsets.csv`. Может быть `\N`. |
| `dialect_id` | Идентификатор диалекта. Может быть `\N`. |
| `dialect_code` | Код диалекта. Может быть `\N`. |
| `affix` | Сохранённый результат выделения конечной части словоформы; см. ниже. |

Одна строка описывает одну связь, а не одну словоформу. Одна и та же форма может повторяться с разными леммами, частями речи, наборами и диалектами. Такие строки не схлопываются.

```csv
wordform_id,wordform,wordform_for_search,lemma_id,gramset_id,dialect_id,dialect_code,affix
8337,avun,avun,2942,3,46,krl-new,vun
8337,avun,avun,2942,56,46,krl-new,vun
```

### Поле `affix`

`affix` — сохранённый в ВепКар результат выделения конечной части словоформы относительно основы, записанной для её леммы. Значение не пересчитывается при экспорте и не является полной морфемной разметкой. Сама основа в выгрузку не входит.

| Значение ячейки | Смысл | Пример |
|---|---|---|
| непустая строка, кроме `#` | Остаток словоформы после основы. | `avun` → `vun` |
| пустая ячейка | Форма совпала с основой, остаток пуст. | `apu` |
| `#` | Служебная метка: форма не подошла под шаблон «основа + остаток». | `kuččuu` |
| `\N` | Значение не определено или не вычислялось. | `en aššu` |

`#` — не аффикс и не лингвистический вывод. Метка не доказывает отсутствие общей основы или супплетивизм: причиной может быть и сама сохранённая основа.

`\N` стоит у всех форм, содержащих пробел. Также его получают формы без грамматического набора и формы лемм, для которых нет сохранённой основы. Причина в поле не записана, поэтому `\N` у конкретной строки нельзя объяснить только по этому файлу.

В признаках для моделей эти четыре состояния следует различать.

## Связь с корпусом

Кандидаты корпуса присоединяются по паре полей:

```text
candidate_analyses_<lang>.wordform_id + gramset_id
        │
        ▼
lemma_wordforms_<lang>.wordform_id + gramset_id
```

Соединение может дать несколько строк на одного кандидата: из-за нескольких лемм или диалектов. Кроме того, не у каждого кандидата есть словарная связь. Отсутствие связи — это отсутствие покрытия, а не повод удалять кандидата.

## Особенности текущей выгрузки

- `gramset_id = 0` встречается в 12 строках (`vep`, `olo`, `lud`). Такого значения нет в `gramsets.csv`.
- В `lemma_wordforms_vep` есть 4 полностью совпадающие строки. Они сохранены как в источнике.
- `dialect_code` не всегда начинается с кода языка файла: например, в `vep` есть строки с `krl-*`, а в `krl` есть префикс `klr-`.
