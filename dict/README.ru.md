# Словарные экспорты

Этот каталог содержит экспорты словаря ВепКар по отдельным словарным значениям для четырёх языковых разновидностей.

```text
meanings_<lang>.csv.zst
        │
        │ meaning_id
        ▼
examples_<lang>.csv.zst
```

Файлы описывают именно словарные значения, а не только леммы-заголовки. У одной леммы может быть несколько строк в `meanings_<lang>.csv.zst`: по одной для каждого самостоятельного значения.

## Файлы

| Шаблон файла | Что представляет строка | Основной идентификатор |
|---|---|---|
| `meanings_<lang>.csv.zst` | Словарное значение леммы | `meaning_id` |
| `examples_<lang>.csv.zst` | Пример, связанный со словарным значением | `id` |
| `morphology/` | Леммы и связи лемм со словоформами | `lemma_id`, `wordform_id` |
| `grammar/` | Граммемы, грамматические наборы и части речи | `gram_id`, `gramset_id`, `pos_id` |
| `samples/meanings_krl.csv` | Небольшой несжатый пример для собственно карельского наречия карельского языка | — |
| `samples/examples_krl.csv` | Небольшой несжатый пример для собственно карельского наречия карельского языка | — |

`<lang>` означает один из кодов: `vep`, `krl`, `olo`, `lud`.

В каталоге [`synonyms/`](synonyms/README.ru.md) находятся синонимические
ряды, их участники, автоматически предложенные кандидаты и данные
о сочетаемости. Они связаны с `meanings_<lang>.csv.zst` через `meaning_id`.

Каталог [`morphology/`](morphology/README.ru.md) содержит все леммы и их словоформы:
`lemma_id` в `meanings_<lang>.csv.zst` ссылается на `morphology/lemmas_<lang>.csv.zst`.
Справочники граммем и грамматических наборов находятся в [`grammar/`](grammar/README.ru.md).

## `meanings_<lang>.csv.zst`

Схема:

```csv
id,meaning_id,lemma_id,meaning_n,lemma,lang,pos,meaning_ru,meaning_en,concept_id,category_id
```

| Поле | Значение |
|---|---|
| `id` | Номер строки внутри данной выгрузки. Может меняться между выгрузками, поэтому для связей не используется. |
| `meaning_id` | Идентификатор словарного значения ВепКар. По нему присоединяются примеры. Почти всегда уникален; см. [ниже](#повторяющиеся-meaning_id). |
| `lemma_id` | Идентификатор словарной леммы-заголовка. |
| `meaning_n` | Номер значения внутри словарной статьи данной леммы. Для объединения файлов используется `meaning_id`, а не `meaning_n`. |
| `lemma` | Написание леммы в соответствующей языковой разновидности. |
| `lang` | Код языка: `vep`, `krl`, `olo` или `lud`. |
| `pos` | Часть речи: например, `NOUN`, `VERB`, `ADJ`, `ADV`, `PART`. |
| `meaning_ru` | Русское словарное толкование или перевод. Может быть пустым, содержать пунктуацию, скобки и несколько значений, разделённых запятыми. |
| `meaning_en` | Английский перевод, внесённый редакторами словаря. Пустое значение означает, что в данном экспортированном источнике английского перевода нет. |
| `concept_id` | Необязательный идентификатор семантического концепта, связанного со значением. Присоединяется к `../semantics/concepts.csv` по `concept_id`. |
| `category_id` | Необязательный идентификатор семантической категории. Присоединяется к `../semantics/concept_categories_wdh.tsv` по `category_id`. |

Пример:

```csv
id,meaning_id,lemma_id,meaning_n,lemma,lang,pos,meaning_ru,meaning_en,concept_id,category_id
1630,48286,42267,1,aškel,krl,NOUN,шаг,step,492,B15
```

Интерпретация:

```text
язык: собственно карельское наречие карельского языка
лемма:                       aškel
номер значения:              1
часть речи:                  NOUN
русское толкование:          шаг
английский перевод:          step
семантический концепт:       492
семантическая категория:     B15
```

### Семантические связи

Семантические поля являются необязательными исходными аннотациями. Пустой `concept_id` или `category_id` означает, что экспорт не даёт такой связи; его нельзя заменять синтетическим значением.

```text
meanings_<lang>.csv
  concept_id ─────────────► ../semantics/concepts.csv
  category_id ────────────► ../semantics/concept_categories_wdh.tsv
```

`concept_id` и `category_id` — это метаданные семантической связи, а не замена `meaning_ru` или `meaning_en`. В частности, не следует автоматически подставлять `concept_en` из `concepts.csv` вместо английского перевода конкретного словарного значения.

### Повторяющиеся `meaning_id`

Значение, связанное с двумя концептами, занимает две строки, которые различаются только `id`, `concept_id` и `category_id`. В текущей выгрузке таких значений два: `30328` в `krl` и `33481` в `lud`.

## `examples_<lang>.csv.zst`

Схема:

```csv
id,meaning_id,example
```

| Поле | Значение |
|---|---|
| `id` | Номер строки примера внутри данной выгрузки. Может меняться между выгрузками. |
| `meaning_id` | Идентификатор словарного значения, которое иллюстрирует пример. Присоединяется к `meanings_<lang>.csv.zst.meaning_id`. |
| `example` | Предложение или фрагмент-пример. Может содержать запятые, кавычки, пунктуацию и повторяющиеся исходные примеры. |

Пример:

```csv
id,meaning_id,example
1,81276,"Делали печи, из этих же кирпичей складывали кучу как печки..."
```

Несколько строк примеров могут относиться к одному `meaning_id`. Повторяющийся текст сохраняется из исходного экспорта и не должен автоматически дедуплицироваться.

## Типичное объединение

```python
import pandas as pd

meanings = pd.read_csv("meanings_krl.csv.zst", compression="zstd", dtype=str)
examples = pd.read_csv("examples_krl.csv.zst", compression="zstd", dtype=str)

joined = examples.merge(
    meanings.drop(columns=["id", "concept_id", "category_id"]).drop_duplicates("meaning_id"),
    on="meaning_id",
    how="left",
    validate="many_to_one",
)
```

Ожидаемая связь:

```text
несколько строк примеров
        │
        ▼
одно словарное значение
```

Семантические поля здесь убраны: иначе из-за [повторяющихся `meaning_id`](#повторяющиеся-meaning_id) проверка `many_to_one` завершится ошибкой. Если эти поля нужны, соединяйте без `validate` и учитывайте, что примеры таких значений удвоятся.

## Чтение файлов

```bash
zstd -dc meanings_krl.csv.zst | head
zstd -dc examples_krl.csv.zst | head
```

Используйте CSV-парсер, а не ручное разбиение строк. И `meaning_ru`, и `example` могут содержать запятые и кавычки.
