# Синонимические ряды и сочетаемость

Каталог содержит данные ВепКар о синонимических рядах (синсетах)
прилагательных олонецкого карельского языка (`olo`): составе рядов,
отклонённых кандидатах на включение и сочетаемости участников.

Участниками рядов являются отдельные словарные значения, а не леммы
целиком. Написание леммы, номер значения и толкования хранятся
в [`../meanings_olo.csv.zst`](../meanings_olo.csv.zst);
описание его полей — в [README словарных экспортов](../README.ru.md).

## Файлы

Полные данные хранятся в UTF-8 CSV-файлах, сжатых Zstandard.
В [`samples/`](samples/) находятся небольшие несжатые примеры.

| Файл | Содержание |
|---|---|
| `synsets_olo.csv.zst` | Синонимические ряды и их доминанты. |
| `synset_members_olo.csv.zst` | Словарные значения, включённые в ряды. |
| `synset_candidates_olo.csv.zst` | Автоматически предложенные значения, не включённые экспертом в соответствующие ряды. |
| `collocations_olo.csv.zst` | Сочетаемость значений, входящих в ряды. |

## Синонимические ряды

Схема `synsets_olo.csv.zst`:

```csv
synset_id,lang,pos,dominant_meaning_id,russian_synonyms
```

| Поле | Значение |
|---|---|
| `synset_id` | Идентификатор синонимического ряда ВепКар. |
| `lang` | Код языка; в текущей выгрузке — `olo`. |
| `pos` | Часть речи; в текущей выгрузке — `ADJ`. |
| `dominant_meaning_id` | Идентификатор словарного значения — доминанты ряда. Может быть пустым. |
| `russian_synonyms` | Русские слова и выражения, характеризующие ряд; поле может быть пустым. |

## Участники рядов

Схема `synset_members_olo.csv.zst`:

```csv
synset_id,meaning_id,syntype_id
```

| Поле | Значение |
|---|---|
| `synset_id` | Ссылка на синонимический ряд. |
| `meaning_id` | Ссылка на словарное значение в `../meanings_olo.csv.zst`. |
| `syntype_id` | Идентификатор типа синонимии в справочнике ВепКар. |

Справочник типов синонимии в текущую выгрузку не включён.

## Отклонённые кандидаты

Схема `synset_candidates_olo.csv.zst`:

```csv
synset_id,meaning_id
```

| Поле | Значение |
|---|---|
| `synset_id` | Идентификатор ряда, для которого было предложено значение. |
| `meaning_id` | Идентификатор предложенного, но не включённого экспертом словарного значения. |

Первоначально кандидаты подбираются автоматически по русским
толкованиям с учётом описания ряда и толкований его участников.
Эксперт включает подходящие значения в ряд; не включённые значения
остаются в списке кандидатов.

Таким образом, в принятом процессе экспертной работы этот файл
представляет отклонённые кандидаты, а `synset_members_olo.csv.zst` —
принятые значения.

Отклонение относится к конкретной паре `synset_id` и `meaning_id`:
оно не означает, что значение не может входить в другой
синонимический ряд.

## Сочетаемость

Схема `collocations_olo.csv.zst`:

```csv
collocation_id,meaning_id,collocate_meaning_id,concept_category_id,display_gloss
```

| Поле | Значение |
|---|---|
| `collocation_id` | Идентификатор записи о сочетаемости. |
| `meaning_id` | Словарное значение участника синонимического ряда. |
| `collocate_meaning_id` | Словарное значение слова-партнёра. |
| `concept_category_id` | Семантическая категория слова-партнёра; соответствует `category_id` в `../../semantics/concept_categories_wdh.tsv`. Может быть пустым. |
| `display_gloss` | Русское пояснение, используемое при отображении сочетаемости. |

Оба поля — `meaning_id` и `collocate_meaning_id` — ссылаются
на `meaning_id` в `../meanings_olo.csv.zst`.

## Связи со словарными значениями

Для получения написания и толкования любого значения присоединяйте
`../meanings_olo.csv.zst` по `meaning_id`:

| Поле в этом каталоге | Поле в `meanings_olo.csv.zst` |
|---|---|
| `synsets.dominant_meaning_id` | `meaning_id` |
| `synset_members.meaning_id` | `meaning_id` |
| `synset_candidates.meaning_id` | `meaning_id` |
| `collocations.meaning_id` | `meaning_id` |
| `collocations.collocate_meaning_id` | `meaning_id` |

Основные поля для представления значения: `lemma`, `meaning_n`,
`pos`, `meaning_ru` и `meaning_en`. Поле `meaning_n` задаёт номер
значения внутри статьи, но не является ключом объединения.
