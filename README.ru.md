# dictorpus-data

Версионируемые экспорты исходных данных из корпуса и словарей ВепКар.

Репозиторий содержит доступные для исследований, воспроизводимой обработки и прикладных задач CSV-данные по четырём языковым разновидностям. Здесь хранятся исходные экспорты и компактные примеры, но не производные результаты моделей, временные файлы, экспериментальные разбиения или личные аннотации.

```text
                    ┌──────────────────────
                    │ corpus/
                    │ texts → sentences
                    │       → words
                    │       → candidates
                    └──────────────────────
                               │
                               │ слово корпуса / контекст
                               │
┌──────────────────────        │       ┌──────────────────────
│ dict/                        │       │ semantics/
│ meanings              ◄──────┼──────►│ concepts
│ examples                     │       │ category → WDH
│ morphology/                  │       │
│ grammar/                     │       │
│                              │       │
│ meaning_id                   │       │ concept_id
│ concept_id            ───────┘       │ category_id
│ category_id                          │ wdh
└──────────────────────                └──────────────────────
```

## Состав репозитория

| Каталог | На какой вопрос отвечает | Основные наборы данных |
|---|---|---|
| [`corpus/`](corpus/README.ru.md) | Какие слова встречаются в текстах, в каком контексте и какие морфологические разборы для них возможны? | `texts_*`, `sentences_*`, `words_*`, `candidate_analyses_*` |
| [`dict/`](dict/README.ru.md) | Какие леммы и словарные значения есть, каковы их русские и английские толкования и какие примеры с ними связаны? | `meanings_*`, `examples_*` |
| [`dict/morphology/`](dict/morphology/README.ru.md) | Какие леммы есть в словаре, какие у них словоформы и какие грамматические наборы и аффиксы с ними связаны? | `lemmas_*`, `lemma_wordforms_*` |
| [`dict/grammar/`](dict/grammar/README.ru.md) | Из каких граммем состоят грамматические наборы и к каким частям речи они применимы? | `grams.csv`, `gramsets.csv`, `gramset_pos.csv`, `parts_of_speech.csv` |
| [`dict/synonyms/`](dict/synonyms/README.ru.md) | Какие словарные значения объединены в синонимические ряды и какова их сочетаемость? | `synsets_*`, `synset_members_*`, `synset_candidates_*`, `collocations_*` |
| [`semantics/`](semantics/README.ru.md) | С какими концептами и доменами WordNet Domains Hierarchy могут быть связаны словарные значения? | `concepts.csv`, `concept_categories_wdh.tsv` |

Каталоги `corpus/`, `dict/` и `semantics/` дополняют друг друга. Это не три альтернативные версии одного и того же набора данных.

## Коды языков

| Суффикс файла | Языковая разновидность |
|---|---|
| `vep` | Вепсский язык |
| `krl` | Собственно карельское наречие карельского языка |
| `olo` | Ливвиковское наречие карельского языка |
| `lud` | Людиковское наречие карельского языка |

Например, `dict/meanings_krl.csv.zst` содержит словарные значения
собственно карельского наречия карельского языка,
а `corpus/words_krl.csv.zst` — словоупотребления корпуса этого наречия.

## Формат файлов

Полные наборы данных — это UTF-8 CSV-файлы, сжатые Zstandard:

```text
*.csv.zst
```

Несжатыми хранятся только небольшие справочники: `dict/grammar/*.csv` и файлы в `semantics/`.

В репозитории также есть небольшие несжатые CSV-примеры в каталогах `samples/`. Они подходят для просмотра на GitHub, знакомства со схемой и быстрых локальных проверок.

Посмотреть сжатый файл без создания несжатой копии:

```bash
zstd -dc dict/meanings_krl.csv.zst | head
```

Прочитать файл через pandas:

```python
import pandas as pd

meanings = pd.read_csv(
    "dict/meanings_krl.csv.zst",
    compression="zstd",
    dtype=str,
)
```

Значения CSV-полей могут содержать запятые, кавычки и сложную пунктуацию. Используйте стандартный CSV-парсер: ручное `split(',')` здесь быстро превращается в археологию ошибок.

В `dict/morphology/` и `dict/grammar/` SQL `NULL` записывается как `\N`, а пустая ячейка означает пустую строку. Правило чтения описано в [README словарной морфологии](dict/morphology/README.ru.md#пустые-значения). В остальных файлах такого маркера нет.

## Политика данных

- Считайте полные `.csv.zst`-файлы неизменяемыми снимками исходных данных.
- Не записывайте в этот репозиторий производные переводы, результаты моделей, train/dev/test-разбиения, предсказания или ручные аннотации.
- Храните воспроизводимые производные наборы в отдельном репозитории или явно выделенном каталоге результатов.
- При объединении таблиц сохраняйте идентификаторы: именно они связывают экспорты между собой.

## Основные связи

```text
corpus/
  texts_<lang>.csv        text_id
       │
       ▼
  sentences_<lang>.csv    sentence_id, text_id
       │
       ▼
  words_<lang>.csv        word_id, sentence_id
       │
       ▼
  candidate_analyses_<lang>.csv    word_id, wordform_id, gramset_id


dict/
  meanings_<lang>.csv     meaning_id, lemma_id, concept_id, category_id
       │
       ▼
  examples_<lang>.csv     meaning_id

dict/morphology/
  lemmas_<lang>.csv           lemma_id, pos_id
       │
       ▼
  lemma_wordforms_<lang>.csv  wordform_id, lemma_id, gramset_id

dict/grammar/
  gramsets.csv            gramset_id, gram_id_*
  grams.csv               gram_id
  gramset_pos.csv         gramset_id, pos_id
  parts_of_speech.csv     pos_id

semantics/
  concepts.csv            concept_id, category_id
  concept_categories_wdh.tsv
                          category_id → wdh
```
