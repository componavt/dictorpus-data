# Семантические ресурсы

Этот каталог содержит семантические метаданные, связывающие словарные значения ВепКар с концептами и метками WordNet Domain Hierarchy (WDH).

```text
../dict/meanings_<lang>.csv.zst
      │                 │
      │ concept_id      │ category_id
      ▼                 ▼
concepts.csv      concept_categories_wdh.tsv
      │                 │
      └──── category_id ┴────► wdh
```

Это небольшие несжатые UTF-8 таблицы с табуляцией в качестве разделителя. Они являются справочными данными, а не результатом работы модели.

## Файлы

| Файл | Назначение |
|---|---|
| `concepts.csv` | Каталог концептов с русскими и английскими названиями и определениями. |
| `concept_categories_wdh.tsv` | Соответствие идентификаторов семантических категорий меткам WordNet Domain Hierarchy. |

## `concepts.csv`

Схема:

```text
category_id\tpos\tconcept_id\tconcept_ru\tconcept_en\tdefinition_ru\tdefinition_en
```

| Поле | Значение |
|---|---|
| `category_id` | Идентификатор семантической категории, например `A11`. Присоединяется к `concept_categories_wdh.tsv.category_id`. |
| `pos` | Часть речи, связанная с концептом. |
| `concept_id` | Идентификатор семантического концепта. К нему присоединяется `../dict/meanings_<lang>.csv.zst.concept_id`. |
| `concept_ru` | Русское название концепта. |
| `concept_en` | Английское название концепта. |
| `definition_ru` | Русское поясняющее определение концепта. |
| `definition_en` | Английское поясняющее определение концепта. |

Пример:

```text
A11	NOUN	1	земля, суша	land, ground	часть земной коры, выступающая над уровнем Мирового океана...	the part of Earth which is not covered by oceans or other bodies of water
```

Концепт шире любого отдельного словарного значения. Его названия и определения — справочные семантические данные; они не должны автоматически перезаписывать `meaning_ru` или `meaning_en` в словарных экспортных файлах.

## `concept_categories_wdh.tsv`

Схема:

```text
category_id\tname_ru\tname_en\twdh
```

| Поле | Значение |
|---|---|
| `category_id` | Идентификатор семантической категории, например `A11`. |
| `name_ru` | Русское название категории. |
| `name_en` | Английское название категории. |
| `wdh` | Одна или несколько меток WordNet Domain Hierarchy, разделённых запятыми. |

Пример:

```text
A11	Небо; небесные тела	Sky; celestial bodies	astronomy
A21	Воды; моря, реки	Waters; seas, rivers	geography, oceanography
```

Поле `wdh` может содержать несколько меток, разделённых запятыми. Потребитель, которому нужны отдельные метки, должен разделить строку по запятым и удалить окружающие пробелы, не меняя исходную справочную таблицу.

## Типичные объединения

### Словарные значения и концепты

```python
meanings.merge(
    concepts,
    on="concept_id",
    how="left",
    validate="many_to_one",
)
```

### Концепты или значения и WDH-категории

```python
concepts.merge(
    categories_wdh,
    on="category_id",
    how="left",
    validate="many_to_one",
)
```

Для словарных значений возможно и прямое объединение:

```python
meanings.merge(
    categories_wdh,
    on="category_id",
    how="left",
    validate="many_to_one",
)
```

Такие операции добавляют семантическое свидетельство. Они не доказывают, что конкретное словарное значение уже имеет английский перевод или найденный WordNet synset.

## Отсутствующие связи

В словарных экспортных файлах `concept_id` и `category_id` могут быть пустыми. Пустое поле означает, что исходный экспорт не содержит соответствующей семантической связи.

Не следует:

- придумывать идентификаторы;
- выводить WDH-метку из написания леммы;
- заменять пропуски универсальным доменом вроде `factotum`.

Отсутствующая аннотация — это отсутствие аннотации, а не загадка, которую CSV обязан разгадать сам. 🙂
